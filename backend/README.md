# backend/ — your service lives here

Build it in your stack (default FastAPI + SQLite). It must implement `contract/openapi.yaml` under the rules in `docs/CONVENTIONS.md` and run on `http://localhost:8000`.

Start from `docs/PROMPTS.md` → "Backend". A worked example (different domain, same rules) is in `reference/` — learn from it, don't submit it.

Document your run command here:

```bash
# e.g.
# python -m venv .venv && source .venv/bin/activate
# pip install -r requirements.txt
# uvicorn app:app --port 8000 --reload
```
