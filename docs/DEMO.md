# Demo script — 4 minutes, screen first

Fill the blanks at 15:30 and dry-run once. Projector shows the consumer page + checker; terminal stays hidden.

1. **The problem (30s).** "In ___ today, finding out ___ takes ___ because the record lives in ___." One sentence on who feels it.
2. **The officer's screen (60s).** Lookup `SBX-___`: verify card appears. Open detail — purpose prompt (`type the case no.`) → record on screen. *(If S1: drop a PDF from documents/, fields appear beside the page, fix one, click Accept.)*
3. **The partner (45s).** Switch identity to PARTNER-AGENCY. Same verify works. Full record → refusal card: code, next step. "Another agency gets the answer it needs — and nothing more."
4. **The receipt (45s).** Access log for that record: every read, who, when, and the stated purpose — including the refusal. "This is what makes data sharing defensible."
5. **The safe write (30s).** File ___ → confirm dialog → receipt with reference no. Replay the same request → same reference, no duplicate.
6. **Close (30s).** Checker score on screen. "Contract is live at /openapi.json — when the national exchange arrives, we change config, not code. Our POC ask: ___ (docs/POC-ASK.md)."

Fallbacks: if Wi-Fi dies nothing changes (all local). If the service crashes, restart takes ___ seconds — practice it.
